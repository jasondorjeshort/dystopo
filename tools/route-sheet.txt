# The route sheet (T289): public routes planned by devtool `route` in every PowerShell sweep (the part `route-sheet`),
# drawn on their map and compared with the previous sweep's by tools/route-diff.py (route-changes.png and .json).
#   python -I tools/route-diff.py run --list tools/route-sheet.txt --out out/sweep-<date>/route-sheet
# One route a line, columns separated by spaces:
#   <name> <pack> <mode> <from lat,lon> <to lat,lon> [<prefer>]
# <name> names the files (<name>.png, .gpx, .json) and pairs the route with its namesake in the previous sweep: never
# rename a line without saying so in the report (a renamed line reads as one removed and one new). <pack> is the pack's
# file name for a public area of areas.json (montblanc for mont-blanc): out/<pack>-outdoors.pmtiles holds the graph (out/<pack>-dem.pmtiles draws the picture); a line
# whose pack is not in out/ is skipped by name, and one whose DEM pack is missing is planned but has no picture.
# <mode> hike|bike|drive; <prefer> time|fuel|quick, drives only. Public places only (areas.json names, no crow lines:
# they use no graph; no line that expects a refusal: a route that is not found fails the part).
