# Task board

[length: the open wave's entries are the goals, Owns lines and checks its agents work from, read whole by the critic and each brief; a closed wave moves to `docs/tasks/`]

Work is split into tasks that don't depend on each other, so several agents can run at once. One agent per task, one git worktree per agent; see `CLAUDE.md` › Working in parallel. Closed waves are in `docs/tasks/`, one record each; this board holds the open wave, Owner actions pending, Later and the follow-up lists.

Every task is done only when: (1) `./gradlew check` passes (existing tests plus new ones); (2) An agent can exercise the feature from the command line and see the result as JSON or PNG; (3) The implementer's report (the merge commit's body, ADR 0043) says what was measured (timings, counts, image observations), using only public areas from `areas.json`.

"Owns" lists the files a task may change freely. Touching anything else should be a few lines at most and called out in the report. Two tasks that both need `MapRenderer.kt` are told below which part is theirs.

**Interacts with:** (optional) names another task of the wave and the mechanism the two share although their Owns lines are disjoint (a hook, a cache, a format, an index, a join); the verifier of whichever merges second runs one scenario across both (ADR 0048).

**Checks:** (from wave 36) after Done when: the JSON items `tools/verify-task.ps1 -Checks` runs (`docs/reference/verifying-a-task.md`), or none; a task whose Done when is wholly in Checks gets a Haiku-class verifier (T296).

### T385. A GPS fix with a wrong time no longer restarts the readout
After T384, in the same slot, never beside it. **Research (2026-11-27, read-only, sources fetched; three apps' sources could not be fetched and are marked unknown in it):** the platform's documentation says a fix's own time "should not be used to order or compare locations" and that its elapsed-realtime stamp is the monotonic one, on the same base as a sensor event's timestamp; one well-regarded open tracker keeps track time on a monotonic clock and ignores GPS time, another orders on the fix's own time (the outlier); the 2019 week rollover gave dates 1024 weeks early with the position fine.
