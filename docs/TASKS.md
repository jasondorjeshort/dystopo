# Task board

Work is split into tasks that don't depend on each other, so several agents can run at once. One agent per task, one git worktree per agent; see `CLAUDE.md` › Working in parallel. Closed waves are in `docs/tasks/`, one record each; this board holds the open wave, Owner actions pending, Later and the follow-up lists.

Every task is done only when:
1. `./gradlew check` passes (existing tests plus new ones).
2. An agent can exercise the feature from the command line and see the result as JSON or PNG.
3. The implementer's report (the merge commit's body, ADR 0043) says what was measured (timings, counts, image observations), using only public areas from `areas.json`.

"Owns" lists the files a task may change freely. Touching anything else should be a few lines at most and called out in the report. Two tasks that both need `MapRenderer.kt` are told below which part is theirs.

**Interacts with:** (optional) names another task of the wave and the mechanism the two share although their Owns lines are disjoint (a hook, a cache, a format, an index, a join); the verifier of whichever merges second runs one scenario across both (ADR 0048).
