# Hatchery's records

The decisions that shaped the practice this tree inherits, and the reference entries Hatchery's hooks and skills cite. Base-owned (ADR 0016, item 5): shipped and updated from Hatchery at the same path in every tree; a project never edits a file here. A project supersedes a record by citation from its own ADR in `docs/design/decisions/` (`adr` skill); Hatchery itself writes its records here.

| Path | What lives there |
|---|---|
| `decisions/` | Hatchery's ADRs, indexed in `decisions/README.md`, "Decisions so far". |
| `reference/` | The reference entries, indexed in `reference/README.md`. |
