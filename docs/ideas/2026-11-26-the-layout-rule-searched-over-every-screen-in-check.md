# The map's layout rule searched over every catalogued screen and font scale in `check`

Source: the triage's agent, generated by claude-opus-5-5 and recorded by claude-fable-5-2, a triage; offered and accepted by the owner; not sanity-checked. Moonshot.

Two waves running, the map's layout rule (`shared/.../ui/OverlayLayout.kt`, driven by `app/MapLayout.kt`) had a fault
that only a sweep on one emulator found: wave 48's T371 (the bar's measure never settling at font 2.0) and wave 49's
T381 (the layout flipping between two arrangements with the bar unfolded and the turn-back card up). Each was an
exchange between what the rule reads and what it last chose, at one window size and one font scale.

The idea: the rule is a pure function, so `check` can search it: over the device catalogue's window sizes, upright
and on its side, the font scales from 1.0 to 2.0, and every set of cards and panels that can be up together, each
arrangement must be a fixed point reached in a bounded number of rounds, with no two boxes overlapping and every
touch target whole. A failing case prints its inputs, which become a unit test.

Lever: a layout fault fails the build instead of a sweep, and T381's own fixed-point test is the first slice of it.
