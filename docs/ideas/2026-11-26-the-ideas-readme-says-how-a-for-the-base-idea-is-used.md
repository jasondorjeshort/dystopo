# The ideas README says how a "For the base:" idea is used here

Source: the update's implementer, generated by claude-opus-5-5 and recorded by claude-fable-5-2, an update; offered and accepted by the owner; not sanity-checked.

Since the update from the base of 2026-11-26 an idea whose title starts `For the base: ` is left to the base: while
it has no block it is not triage's and no pass builds it, the base's triage lists it, and the update that finds the
base's `Base-idea:` commit deletes it. That rule is in `.claude/rules/docs.md` (Queues) and the `brainstorm` skill
("After an update from the base"), which load only when their paths are touched or the skill runs. `docs/ideas/README.md`,
the file a reader of the queue opens first, does not mention it, and the queue now holds such a file.

The edit: one sentence in `docs/ideas/README.md`, under what drains the queue, saying what the prefix means here and
pointing at the rule; and a check that `node .claude/hooks/queue-list.js ideas` shows such a file in a way a triage
will not mistake for untriaged work of its own.
